# Function Arguments

Examples of the ways Python functions receive arguments.

## Concepts

- Positional arguments: `foo(1, 2, 3)`.
- Keyword arguments: `foo(a=2, b=3, c=1)`.
- Default values: `d` defaults to `4`.
- Sequence unpacking with `*my_list`.
- Mapping unpacking with `**my_dict`.
- The commented `goo` example shows `*args` and `**kwargs` for collecting
  additional arguments.
- The `loo` example reads a module-level value from its enclosing global scope.

## Run

```powershell
python .\funarg\func.py
```
